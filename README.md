# Online Tailoring Order Management System

## Project Description

The Online Tailoring Order Management System is a Java-based project designed to manage customer details, garment measurements, and tailoring orders.

## Technologies Used

- Java 17
- Maven
- JUnit 5
- Git and GitHub
- Jenkins

## Core Modules

1. **Customer:** Validates customer details, email, phone number, and password.
2. **Measurement:** Validates garment measurements and standard ranges.
3. **TailoringOrder:** Validates tailoring orders and manages order status.

## Run the Project Tests

Make sure Java 17 and Maven are installed. Open a terminal in the project directory and run:

```bash
mvn test
```
